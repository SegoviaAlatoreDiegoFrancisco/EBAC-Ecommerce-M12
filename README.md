# Tienda Adidas
Proyecto frontend de una tienda deportiva inspirada en la estética Adidas, desarrollada con HTML y CSS para mostrar un catálogo de productos promociones yu carrito de compras visual.

## Descripción general
Este proyecto simula una landing page de ecommerce para venta de productos deportivos, con una estructura moderna y una paleta de colores clara. La interfaz esta enfocada en una experienca visual de compra rapida con atención a la tripografía, imágenes de productos, descuentos y un carrito lateral. 

## Tecnologías utilizadas
- HTML5 para la estructura del contenido.
- CSS3 para el diseño visual
- SCSS para reutilización de estilos y su organización
- Media Queries para tener un diseño responsivo.
